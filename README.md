# FUTURE_DS_01
📊 Task 1 – Business Sales Performance Dashboard
🔹 Description
The Business Sales Performance Dashboard is an interactive data visualization project designed to analyze and monitor overall sales performance. It transforms raw business data into meaningful insights, helping in better decision-making and performance tracking.
🔹 Objective
The main objective of this task is to:
Understand sales patterns and trends over time
Evaluate business performance using key metrics
Identify top-performing categories, regions, and products
Present insights in a visually appealing and easy-to-understand format
🔹 Key Features
KPI Metrics:
Total Revenue
Total Orders
Average Order Value
Total Profit
Visual Insights:
Monthly Sales Trend (line chart for growth analysis)
Sales by Category (comparison across product types)
Sales by Region (distribution using pie chart)
Top Selling Products (ranking of best performers)
Interactive Elements:
Region filter (West, East, Central, South)
Category filter (Technology, Furniture, Office Supplies)
🔹 Tools & Technologies Used
Microsoft Excel
Data Cleaning & Transformation
Charts & Dashboard Design

🚀 Customer Retention & Churn Analysis Dashboard – Task 2 Completed

I’m excited to share my latest project where I built an interactive Customer Retention & Churn Analysis Dashboard using Power BI.

📊 This dashboard provides a comprehensive view of customer behavior, helping identify key churn patterns and retention strategies.

🔍 Key Insights:
• Customers with month-to-month contracts show the highest churn
• Early-stage customers (first 6 months) are at maximum risk
• Higher monthly charges are strongly linked to increased churn
• Long-term contracts significantly improve customer retention

📈 What I Built:
✔ KPI tracking (Total Customers, Churn Rate, Retention Rate)
✔ Churn analysis by contract type, tenure, and pricing
✔ Cohort analysis to understand retention trends over time
✔ Interactive filters for deeper insights

💡 Key Takeaway:
Improving early customer experience, optimizing pricing strategies, and encouraging long-term commitments can significantly reduce churn and drive business growth.

🛠️ Tools Used:
Power BI | Data Analytics | Data Visualization
