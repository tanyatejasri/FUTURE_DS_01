# FUTURE_DS_01
📊 Task 1 – Business Sales Performance Dashboard
🔹 Description
The Business Sales Performance Dashboard is an interactive data visualization project designed to analyze and monitor overall sales performance. It transforms raw business data into meaningful insights, helping in better decision-making and performance tracking.
🔹 Objective
The main objective of this task is to:
Understand sales patterns and trends over time
Evaluate business performance using key metrics
Identify top-performing categories, regions, and products
Present insights in a visually appealing and easy-to-understand format
🔹 Key Features
KPI Metrics:
Total Revenue
Total Orders
Average Order Value
Total Profit
Visual Insights:
Monthly Sales Trend (line chart for growth analysis)
Sales by Category (comparison across product types)
Sales by Region (distribution using pie chart)
Top Selling Products (ranking of best performers)
Interactive Elements:
Region filter (West, East, Central, South)
Category filter (Technology, Furniture, Office Supplies)
🔹 Tools & Technologies Used
Microsoft Excel
Data Cleaning & Transformation
Charts & Dashboard Design
